## 当前结论

OpenArm 始终是当前适配目标，MQ03 是数据源机器人，Panda 是历史重选实验和回归夹具。

- **只约束位置：** 60 帧 calibration 上，左臂 57/60（95%）、右臂 54/60（90%），同帧两侧独立求解均成功 51/60（85%）。

- **代码：** 通用求解、OpenArm Profile/夹爪、M1a/M1b 的若干契约与合成测试已实现。它们不等于 OpenArm 私有数据的 M1a/M1b 出口已完成。
- **当前检查点：** 整理提交已推送；原run004的中断记录保留，续跑在新run005完成，随后run006完成双臂联合验证。下一步定位20帧残差失败，不扩大评估规模。

“单帧”指时间采样，不等于“单臂”。“两侧各自≥80%”也不等于“同帧双侧≥80%”。所有百分比必须同时带机器人、目标约束、样本数、碰撞口径和 recipe。

历史报告的 `status=PASS` 通常只表示脚本完成；不能替代运动学闸门。特别是 9 月 9 日 shortlist 报告的 `joint_nominal_rate` 实际为两侧比例的较小值，不能解释成实测双臂同帧成功率。

这些是相对 anchor 的增量，不是完整 source-to-target 外参。不同网格可复用 `t2-020` 等名称；唯一引用必须是 **run ID + candidate ID + recipe/report hash**。

左右工具候选来自数据筛选：左 `[[0,-1,0],[0,0,1],[-1,0,0]]`，右 `[[0,0,-1],[1,0,0],[0,-1,0]]`。它们不能因为 IK 分数高就被称为真实物理工具坐标。目标左右手局部结构相同，也不自动证明跨机器人功能轴必须使用同一个矩阵。
