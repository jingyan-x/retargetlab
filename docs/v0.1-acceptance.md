## 已执行验证

- Ubuntu 20.04.6 LTS / Python 3.12.14 上新建不继承系统 site-packages 的处理与读取 venv；使用 pip 从候选 wheel 安装。依赖约束随候选包提供。
- 从 GitHub 新克隆公开 OpenArm 仓库并检出固定提交；在仓库以外的工作目录、移除 PYTHONPATH 后执行 demo-init、process、training-export、build-mujoco-model、replay-build。
- 192时刻、384条双流求解记录；Pink 和 Mink 均有190个双流合格时刻，2个故意制造的失败时刻保留并剔除。限位/输出速度检查通过，六个测试视频保留。
- 独立读取环境未安装 Pinocchio/Pink/Mink；真实 LeRobotDataset + MaskedLeRobotDataset 读取130个完整16步窗口，视频三路均为 [3,64,96]，批次 state 为 [2,16]、action 为 [2,16,16]，任务文字、双流、无跨 Episode/失败行、无填充和归一化有限性检查通过。
- 源码回归213通过、1跳过；跳过项为求解环境没有 LeRobot，读取闭环在独立环境另行执行。新增测试覆盖公开示例处理/导出、CLI版本/帮助、来源拒绝与回放配置相对路径。
- 安装包的 WebGL 页面可显示公开示例和原质量标记。灰白地面背面不遮挡低视角模型；后端选择仅列出当前 bundle 实际包含的后端。

完整机器可读验收记录、命令日志和哈希保存在本轮交付 run 中。开发过程中发现并修复了读取 extra 不完整、回放配置相对路径受当前目录影响和单后端 bundle 仍显示其他后端的问题。

## 使用边界

这是一份可安装、可复现的软件候选，不是机器人性能泛化或真实任务验收。动态夹爪、精确物理接触、独立留出、全148ep、动力学和训练不在本次声明内。公开示例不含私有数据；原模型/实验结果和默认避碰配置保留。

项目自身开源许可证尚待选择。候选包供本地审阅与使用，尚未公开发布到 GitHub/PyPI；第三方 Three.js 和下载的 OpenArm 模型分别保留 MIT、Apache-2.0 文件。首次安装和模型下载需要网络，数据生成后的回放/读取可本地运行。
