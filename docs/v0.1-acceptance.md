# Public validation

The CLI 0.1.0rc4 release was validated on Linux x86_64/Python 3.12 using a public OpenArm model pinned to `6148297241fb0402eafe2c6eed455ae4e90d4552` and generated synthetic data. Its [tagged CI](https://github.com/jingyan-x/retargetlab/actions/runs/34937426332) completed successfully.

The public example contains two episodes, 192 timestamps and three synthetic camera streams. Both backends produce 190 eligible paired rows and 130 intact 16-step windows. Deliberate target jumps exercise failures; failed rows stay present and are masked. Actual LeRobot/PyAV reading verifies values, images, task metadata, episode boundaries, padding and batch normalization. Reader smoke also covers other horizons and a singleton eligible batch.

For Skill 0.1.0, a new complete two-environment installation passed pip/CLI/import checks, including CoACD and plotting. Four installer boundary tests cover existing-prefix preservation, wrong-archive rejection, incomplete-installation read-only behavior and unchanged installed files during a full check. Two actual CLI negative cases exercise an existing process output and an unsupported input layout.

An independent agent used the Skill to complete the public Pink example, export, actual 16-step reading and replay HTTP/model/motion checks. A separate agent reviewed six interaction scenarios. Those dialogue reviews are not six actual runtime executions; browser interaction and physical execution were not part of that forward task.

The Skill release workflow repeats complete installation, installer tests and installed-wheel public smoke in GitHub-hosted environments. Private laboratory data are not needed and are not uploaded as validation artifacts. See the workflow run attached to the Skill release for its final status.
